Si aún ves "Error: Datos del producto no disponibles":

1. RECARGAR COMPLETAMENTE
   - Presiona Ctrl+Shift+R (recarga completa)
   - O Ctrl+F5 (limpiar caché y recargar)

2. VERIFICAR SERVIDOR
   - El servidor debe estar corriendo en el puerto 8000
   - python -m http.server 8000

3. VERIFICAR CONSOLA
   - Abrir F12 > Console
   - Buscar mensajes de error en rojo
   - Anotar qué producto específico falla

4. USAR DIAGNÓSTICO
   - Abrir diagnostico.html
   - Ver qué archivos tienen errores

5. VERIFICAR ARCHIVO ESPECÍFICO
   - Si un producto falla, verificar que su archivo .txt exista
   - El archivo debe tener más de 100 caracteres
   - Debe contener HTML válido con <style>
